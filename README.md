# PCL 原版下载恢复工具

第三方独立工具。选择现有 PCL EXE，自动分析其中的原版下载限制，生成恢复下载的副本，原文件保留。

**[下载最新版](https://github.com/YousaHay/PCL2-Download-Restore/releases/latest)** · [使用说明](使用说明.txt) · [验证记录](验证记录.txt)

## 使用

1. 在 Releases 下载 EXE，或下载工具包并解压。
2. 运行工具，点击“选择文件”，选择自己的 PCL 启动器。
3. 工具定位到限制后，点击“生成恢复下载的副本”，保存到原启动器所在目录。
4. 关闭原启动器，再运行生成的副本。

运行环境：Windows、.NET Framework 4.8。完全离线，程序集分析库已内嵌，运行 EXE 无需额外安装依赖。

工具只读取输入 EXE 并写入新的 EXE，不改动原启动器、游戏、账号、注册表或配置。需要恢复原行为时，直接使用原启动器。

## 识别方式与范围

v1.2 不按版本号、固定文件大小或整文件 SHA-256 白名单筛选，而是分析实际 .NET 方法、字段和 IL 指令，动态定位修补位置及字段编号。

- 恢复下载页原有的原版版本列表加载器。
- 能明确识别时，同时恢复版本修改页的原版入口。
- 已正常的下载入口会提示无需处理。
- 整合包安装限制仍保留。微软登录、正版校验、主题、更新和 CurseForge 等功能不作修改。

**不限固定版本不代表保证所有版本兼容。** 加壳、混淆、删除了下载实现或完全改变流程的构建，可能无法识别。工具会显示原因，不会强行修补未知结构。

## 从源码构建

仓库包含构建所需的 dnlib 4.5.0 DLL；Windows 自带的 .NET Framework C# 编译器可构建本工具。

```powershell
.\build.ps1
```

输出为 `PCL原版下载恢复工具.exe`。`dnlib.dll` 在构建时嵌入 EXE，运行时无需旁置 DLL。

命令行接口：

```powershell
& '.\PCL原版下载恢复工具.exe' --check '原启动器.exe'
& '.\PCL原版下载恢复工具.exe' --patch '原启动器.exe' '新副本.exe'
```

`--check` 返回码：`0` 定位到可处理限制，`2` 已正常且无需处理，`1` 无法识别或出错。`--patch` 返回码：`0` 成功，`1` 未生成副本或失败。已有文件不会被覆盖。
